# Grow My Therapy — Dr. Maya Reynolds

Next.js front-end assignment project with a profile-based therapist redesign.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run build
npm run start
```

## Project highlights

- Homepage structure follows the reference site's major content rhythm.
- Dr. Maya Reynolds is the single source of truth for the redesigned copy.
- Adult-focused services: Anxiety & Panic, Trauma & EMDR, Burnout & Perfectionism.
- New Who I Help, Areas of Expertise, How I Work, Specialties, Our Office and Schedule sections.
- Premium editorial color palette with interactive hover states.
- Maya portrait uses a real `<img>` element so the portrait is not forced into a cropped background.
- Responsive desktop, tablet and mobile layouts.
- FAQ accordion and mobile navigation.
